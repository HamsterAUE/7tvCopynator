# 7tvCopynator

Консольная утилита на Python для упрощения копирования наборов эмодзи (Emote Sets) между аккаунтами на платформе **7TV** через официальный GQL API.

---

##  Как это работает

1. **Проверка авторизации:** Скрипт проверяет наличие сохраненного токена в файле `cfg.json`. Если токен валиден, запускается процесс копирования.
2. **Умная авторизация (если токена нет):** * Скрипт находит в реестре Windows браузер по умолчанию (**Yandex**, **Chrome** или **Edge**).
* Запускает его в изолированном системном режиме (без каких-либо флагов автоматизации, которые ограничиваются защитой Twitch).
* Открывает официальную страницу логина 7TV через Twitch.
* Как только пользователь успешно входит в аккаунт, скрипт методом сниффинга файлов базы данных `leveldb` на жестком диске вытягивает сгенерированный `7tv-token`


3. **Клонирование:** Программа предлагает выбрать, из какого сета и в какой сет нужно скопировать эмодзи, после чего переносит их поштучно с учетом лимитов запросов (Rate limits) к 7TV, что, к сожалению, замедляет процесс.

## 🛠️ Инструкция по установке и запуску

### Запуск из исходного кода

1. Убедись, что у вас установлен Python 3.10+.
2. Клонируй репозиторий и перейди в папку проекта:
```bash
git clone https://github.com/HamsterAUE/7tvCopynator.git
cd 7tvCopynator

```


3. Создайте виртуальное окружение и активируй его:
```bash
python -m venv .venv
# Для Windows:
.venv\Scripts\activate

```


4. Установи единственную необходимую библиотеку `requests` (для работы с сетью):
```bash
pip install requests

```


5. Запусти скрипт:
```bash
python main.py

```



---

## 📦 Сборка в автономный `.exe` файл

Для сборки используйте утилиту `pyinstaller`:

1. Установите PyInstaller в виртуальное окружение:
```bash
pip install pyinstaller

```


2. Соберите проект в один исполняемый файл:
```bash
pyinstaller --onefile --name="7tvCopinator" main.py

```


3. Готовый файл появится в папке `dist/7tvCppinator.exe`.

Вы можете скачать готовую сборку для Windows:

## ⚠️ Примечания

* **Безопасность:** Программа не видит, не запрашивает и не сохраняет пароли от Twitch. Все данные авторизации обрабатываются внутри вашего браузера. Скрипт считывает только готовый токен сессии 7TV.
* **Анти-спам лимиты:** В процессе копирования заложена задержка в `0.4` секунды между эмодзи. Это необходимо, чтобы серверы 7TV не заблокировали IP-адрес по ошибке `429 Too Many Requests`.
